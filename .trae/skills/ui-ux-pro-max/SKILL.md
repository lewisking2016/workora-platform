# UI/UX Pro Max - Design Intelligence

This skill provides comprehensive design intelligence to move beyond generic AI-generated interfaces.

## Core Principles
1. **Industry-Specific Reasoning**: Analyze the product type (e.g., B2B SaaS, Marketplace) to determine typography, color moods, and UX patterns.
2. **Design System First**: Create a single source of truth for UI (styles, colors, components) before implementation.
3. **Accessibility & Touch**: Priority 1 is always accessibility and touch targets (minimum 44x44px).
4. **Anti-Patterns**: Avoid "AI purple" gradients, generic hero sections, and cluttered layouts.

## Usage Guidelines
- Use "Dials" to tune output: `variance` (1-10), `motion` (1-10), `density` (1-10).
- Follow stack-specific rules (e.g., Next.js App Router conventions).
- Implement a pre-delivery checklist: contrast check, safe areas, consistent spacing.
